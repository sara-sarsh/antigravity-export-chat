# 🚀 مهارت استخراج و انتقال گفتگوهای Google Antigravity
### Antigravity Chat Export & Migration Skill

یک مهارت تخصصی و کامل برای **Google Antigravity** جهت استخراج، اشتراک‌گذاری و انتقال (Migration) سوابق پروژه‌ها و گفتگوها بین رایانه‌ها و همکاران.

---

## 🌟 ویژگی‌های کلیدی

1. **استخراج تمیز مارک‌داون (Readable Markdown Export):**
   - تبدیل رونوشت‌های سیستمی (`transcript.jsonl`) به فایل‌های تمیز و خوانا با فرمت GitHub Flavored Markdown.
   - تفکیک خودکار پیام‌های کاربر و پاسخ‌های هوش مصنوعی.
   - قرار دادن فرآیند فکری مدل (Thinking) و فراخوانی ابزارها در بخش‌های تاشو (`<details>`).
   - پشتیبانی بومی از راست‌به‌چپ (RTL) برای مکالمات فارسی.

2. **بسته‌بندی کامل و قابل انتقال (Full Antigravity Migration Package):**
   - شناسایی هوشمند تمام گفتگوهای مرتبط با یک پروژه از طریق جدول `conversation_summaries.db`.
   - یکپارچه‌سازی و تهیه نسخه پشتیبان تمیز از پایگاه‌های داده SQLite (`conversations/*.db`) با تجمیع فایل‌های WAL.
   - استخراج کامل سوابق مغز (`brain/*`) شامل لاگ‌ها و اسناد طراحی (`implementation_plan.md` و `walkthrough.md`).

3. **اسکریپت واردسازی خودکار (`import_to_antigravity.py`):**
   - عملکرد چندسکویی (ویندوز، مک و لینوکس) بدون نیاز به وابستگی خارجی (Pure Python 3).
   - انتقال خودکار فایل‌ها به دایرکتوری داده‌های Antigravity و ثبت متادیتا در لیست چت‌های برنامه.

---

## 📥 نحوه نصب در Google Antigravity

برای افزودن این مهارت به Antigravity خود:

```bash
# ایجاد دایرکتوری مهارت
mkdir -p ~/.gemini/config/skills/export-chat

# دانلود فایل SKILL.md
curl -sSL https://raw.githubusercontent.com/sara-sarsh/antigravity-export-chat/main/SKILL.md -o ~/.gemini/config/skills/export-chat/SKILL.md
```

پس از دانلود، این مهارت به طور خودکار توسط Antigravity شناخته شده و با دستوراتی مانند *"سوابق چت این پروژه را زیپ کن و خروجی بده"* فعال می‌شود.
